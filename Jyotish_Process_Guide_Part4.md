## Glossary of Core Terms

| Term | Meaning |
|------|---------|
| Ayanamsa | Angular gap between tropical and sidereal zodiac (~24°) |
| Bhava | House (one of 12 divisions of the chart) |
| Dasha | Planetary period system governing timing of events |
| Drishti | Aspect — a planet’s visual ray on another house or planet |
| Dusthana | Difficult house (H6, H8, H12) |
| Gana | Temperament class (Deva/Manushya/Rakshasa) — for compatibility |
| Gochara | Transit — real-time planetary movement over natal positions |
| Graha | Planet (lit. “seizer” — that which grips the soul) |
| Karakata | Significator (planet naturally representing a theme) |
| Kendra | Angular house (H1/H4/H7/H10) — power positions |
| Lagna | Ascendant — rising sign at birth |
| Mahadasha | Major planetary period |
| Moolatrikona | Special powerful sub-zone within own sign |
| Nakshatra | Lunar mansion (one of 27 star-groups of 13°20′ each) |
| Nirayana | Sidereal zodiac (fixed stars as reference) |
| Pada | Quarter of a nakshatra (3°20′ each; 4 per nakshatra) |
| Pancha Mahapurusha | Five great-person yogas (Ruchaka/Bhadra/Hamsa/Malavya/Sasha) |
| Parivartana | Mutual exchange of signs between two planet lords |
| Sāyana | Tropical zodiac (vernal equinox as reference) |
| Shadbala | Six-fold strength measurement system for planets |
| Trikona | Trine house (H1/H5/H9) — most auspicious seats |
| Upachaya | Growing house (H3/H6/H10/H11) |
| Varga | Divisional chart (D1, D9, D10, etc.) |
| Vargottama | Same sign in D1 and D9 — maximum strength |
| Yoga | Planetary combination producing specific results |
