0. D-Chart Computation Method — Debug Reference

General D-N Lagna Derivation Formula (Parāśarī — used throughout this document):

  • Each sign = 30°. Each D-N portion = 30°/N degrees.
  • Degree in sign ÷ (30/N) = portion index (1-based: floor of (degree × N / 30) + 1).
  • Odd signs: count portion N from the sign itself (1st = same sign, 2nd = next sign, etc.).
  • Even signs: D3 counts from 5th/9th; D4 counts from same/4th/7th/10th; D7 counts from 7th sign. Rules vary by D-number — see per-chart derivations below.
  • Navāṁśa (D9): for fire lagnas → start Aries; earth → Capricorn; air → Libra; water → Cancer.
