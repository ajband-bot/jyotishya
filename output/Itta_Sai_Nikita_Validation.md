That is exactly what happened here: Jupiter owns H1 (Lagna, always trikoṇa) and H10 (kendra), so the naive check returns True. The Raghunandan file's §6 documented a related but distinct H1-double-counting artifact; this is a **new, separate bug** in the same function, worth flagging to whoever next touches `is_yoga_karaka()` — it likely misfires the same way for every dual-sign Lagna (Gemini, Virgo, Sagittarius, Pisces) where the table already shows `yoga_karaka: null`.
